Откройте репозиторий anatoly-cherdakov/parkrun.
Загрузите в него содержимое архива, сохранив структуру:

index.html — заменить существующий файл в корне репозитория;
run5k-results.json — добавить рядом с index.html;
scripts/fetch_run5k.py — добавить в папку scripts;
.github/workflows/refresh-run5k.yml — добавить с указанным путём.

Дополнительную папку parkrun внутри репозитория создавать не нужно.

В настройках репозитория Actions → General → Workflow permissions разрешите
Read and write permissions, если автоматический коммит не имеет прав.
Первый запуск можно выполнить в Actions → «Обновление результатов run5k»
→ Run workflow. Далее снимок обновляется по расписанию каждые 15 минут
(GitHub может задержать запланированный запуск).

Кнопка читает снимок и добавляет только результаты после последней даты
на странице. Добавленные строки сохраняются в браузере, но файл HTML
в репозитории сам по себе не меняется. На другом устройстве кнопка
прочитает тот же свежий снимок из репозитория.
